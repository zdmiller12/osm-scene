# Python Notebooks

Install `notebook` group to use notebooks.

```sh
poetry install --with notebook
```

## Universal Scene Description Files

`.usd*` files can be consumed by the folllowing

- [Houdini](https://www.sidefx.com/), which offers a free tier called [Houdini Apprentice](https://www.sidefx.com/buy/#houdini-education)
- [blender](https://www.blender.org/) (*personal preference*)
- [usdview](https://openusd.org/release/toolset.html#usdview)
